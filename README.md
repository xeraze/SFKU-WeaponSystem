# SFKU — Weapon System

Система оружия для Roblox-проекта **SFKU** (portfolia-работа, заказчик — Delk).

## Возможности

- Подбор оружия с карты (ProximityPrompt), ношение нескольких стволов
- Стрельба: raycast-хитскан, урон с дистанционным спадом, хедшот ×2
- Полуавтомат / полный автомат (по типу оружия), болтовые снайперки
- Перезарядка с таймером, скрытием магазина, резервом патронов
- ADS (ПКМ, только от первого лица) с сужением разброса
- Хитскан-кастомизация: `WeaponConfig` — урон, скорострельность, магазин, разброс, дальность
- Авто-резолв характеристик для моделей с любым именем (fallback-конфиг)

## Структура

```
ReplicatedStorage/Modules/          — Config, DataStore, Weapon (Config/Parser/Validator)
ServerScriptService/Server/         — MainServer + системы (роли, двери, КПЗ, оружие и др.)
StarterPlayerScripts/               — клиент: HUD оружия, взаимодействия, меню
StarterGui/MainMenu/                — загрузочный экран и меню выбора ролей
```

## Установка (Roblox Studio)

1. Открыть.place, включить **Game Settings → Security → Enable Studio Access to API Services** (нужен встроенный DataStore).
2. Command Bar (режим Edit): вставить `cmd_1` … `cmd_6` по порядку. Все батчи < 100k символов.
3. Play. Оружие подбирается с земли клавишей **E**.

`generate_batches.ps1` пересобирает `cmd_*.lua` из исходников (пригодится при правках).

## Ограничения

- Анимации и звуки выстрела — не реализованы (в компетенции аниматора).
- Геометрия/масштаб/крепления — на стороне моделей пака; модификации оружия невозможны без точек крепления в моделях.
